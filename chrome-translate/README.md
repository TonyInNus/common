# 划词翻译 · Chrome 英语翻译插件

选中网页中的英文一键翻译成中文。基于 Manifest V3，无需任何 API Key，完全免费。

## 功能

| 功能 | 用法 |
|---|---|
| 划词悬浮翻译 | 在网页中选中文本 → 选区旁出现「译」按钮 → 点击显示译文气泡 |
| 右键菜单翻译 | 选中文本 → 右键 → 「翻译选中文本」 |
| 快捷键翻译 | 选中文本 → 按 `Alt+T` |
| 弹窗翻译 | 点击工具栏图标 → 输入/粘贴文本 → 翻译（`Ctrl+Enter` 快速翻译） |
| 朗读译文 | 弹窗中点击「朗读」，用目标语言 TTS 发音 |
| 复制译文 | 弹窗或气泡中一键复制译文 |
| 目标语言选择 | 支持 12 种语言，选择后自动记忆 |

## 安装（加载已解压的扩展程序）

1. 打开 Chrome，地址栏输入 `chrome://extensions` 回车
2. 打开右上角 **开发者模式** 开关
3. 点击左上角 **加载已解压的扩展程序**
4. 选择本目录：`chrome-translate`
5. 完成！工具栏会出现「译」字图标

> 快捷键 `Alt+T` 可在 `chrome://extensions/shortcuts` 中修改。

## 翻译服务（自动兜底）

按顺序尝试以下免费接口，某个失败或不可用时自动切换下一个；失败的服务会熔断 10 分钟，避免每次等待超时：

1. **Google** 非官方接口（质量最好；部分网络环境不可用）
2. **彩云小译**（国内直连、质量好，使用公开演示 token，无需注册）
3. **MyMemory** 免费接口（最终兜底，全网络可用）

无 API Key、无用量费用，适合个人日常使用。

## 目录结构

```
chrome-translate/
├── manifest.json    # MV3 清单
├── background.js    # 后台：翻译服务调度、右键菜单、快捷键
├── content.js       # 页面脚本：划词按钮 + 译文气泡（Shadow DOM 隔离样式）
├── popup.html       # 弹窗页面
├── popup.css        # 弹窗样式（Flat 设计，支持深色模式）
├── popup.js         # 弹窗逻辑
└── icons/           # 16/48/128 图标
```

## 常见问题

- **选中文字后没有「译」按钮？** 只支持普通网页（http/https），`chrome://` 内置页、Chrome 商店、PDF 阅读器等不支持；文本框内选词也不支持（请用弹窗）。
- **提示翻译失败？** 检查网络；三个免费接口都不可用时才会报错。
- **想改默认翻译目标语言？** 打开弹窗，选择语言后自动保存。
